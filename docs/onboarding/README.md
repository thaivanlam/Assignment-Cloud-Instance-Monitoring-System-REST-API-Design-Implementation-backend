## Which document do I want?

| If you want to… | Read |
|---|---|
| Understand the source, function by function | [READING_ORDER.md](READING_ORDER.md) |
| See the API work before reading any code | [../demo/WALKTHROUGH.md](../demo/WALKTHROUGH.md) |
| Understand the layering rather than the functions | [../design/ARCHITECTURE.md](../design/ARCHITECTURE.md) |
| Call an endpoint without reading the source | [../api/ENDPOINTS.md](../api/ENDPOINTS.md) |

[READING_ORDER.md](READING_ORDER.md) assumes the API is running and links out to the
documents above at the point where each becomes useful, so it works as the single
entry point for a new contributor.
